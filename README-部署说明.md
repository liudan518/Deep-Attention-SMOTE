# DA-SMOTE-ED 论文项目网站（五语种版）

基于原版 *Deep Attention SMOTE* 网页进行视觉、响应式排版及本地化优化；论文研究数据、六张原图和原 PDF 均予以保留。

## 文件结构

- `index.html`：主页面；内嵌布局与样式。
- `i18n.js`：内置五语种翻译与切换逻辑（中文、英文、俄语、法语、阿拉伯语）。
- `images/`：六张原始论文插图，点击可放大。
- `S0166361523001227.bib`：与用户提供的 BibTeX 附件一致。
- `Deep Attention SMOTE.pdf`：原始论文 PDF（原压缩包随附）。

## 本地预览

解压后打开 `index.html`。网页的文字、图像和翻译文件均为本地资源；首次使用时若不能加载 Google Fonts，会自动使用系统字体。语言菜单位于页面顶部；偏好保存在当前浏览器的本地存储中（若浏览器禁用本地存储，仍可正常手动切换语言）。

## 部署到 GitHub Pages

1. 解压 ZIP 文件。
2. 将其中 `DA-SMOTE-ED-Website` 文件夹内的**所有内容**上传至 GitHub 仓库根目录（或 Pages 的指定发布目录），保留 `images` 的相对路径。
3. 在 GitHub 仓库 **Settings → Pages** 中设置发布分支与目录。
4. 发布后打开站点，测试语言菜单、图片放大和 BibTeX 的复制与下载。

无需构建工具、后端服务或第三方国际化库；可直接以静态站点部署。

## 设计调整

采用深色科研主题、青蓝色渐变重点信息、柔和网格背景、统一的卡片留白及边框；长段落使用两端对齐，兼顾中英文排版；六张论文图按横纵比展示、限制显示高度，支持点击放大。移动端使用折叠菜单；阿拉伯语界面自动启用 RTL 布局，并保护公式、表格与 BibTeX 的阅读方向。针对原表 VII 的 14 行方法，修正个别旧版“13 methods”总数描述，但保留“13 个对比方法”的语义。

## BibTeX

引用卡片显示完整的原始 `.bib` 内容（包含 `url`、`keywords` 和 `abstract` 字段），复制按钮与下载按钮使用同一条目，不会因切换界面语言而改变论文的官方引用信息。
