## GitHub Pages 部署 / Deployment

维护者首次启用 Pages / Initial setup for the repository owner:

1. 打开 [Settings → Pages](https://github.com/liudan518/Deep-Attention-SMOTE/settings/pages)。
2. Source 选择 **Deploy from a branch**；发布分支选择 **main**，目录选择 **/(root)**。
3. 点击 **Save**，等待 GitHub Pages 的构建和部署任务成功。

首次部署完成后，科研主页、论文 PDF 与 BibTeX 可无需登录公开访问。后续更新 `main` 分支时会自动重新部署。
After the first deployment, the website, PDF and BibTeX are public and require no sign-in. Updates to `main` automatically redeploy the site.
